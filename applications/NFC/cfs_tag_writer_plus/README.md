# CFS Tag Writer+

Source: https://github.com/BaniMun/cfs-tag-writer

A fork of [CFS Tag Writer](https://github.com/pwschattenberg/cfs-tag-writer) by
P. Schattenberg (MIT). It uses its own app id, so both apps can be installed
side by side; on first run it copies the original's saved tags and settings.

Changes from the original: redrawn screens (main menu with icons, a spool card
for read results and the write confirm screen, animated read / write / erase
screens), a one-screen color picker with 240 named shades grouped by family,
and Retry after a failed read, write, or erase.
