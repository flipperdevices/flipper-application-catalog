# Maze 3D

First-person 3D raycasting maze game for Flipper Zero, with:

- 50-level Campaign (pure maze → keys & doors → enemy combat)
- Minecraft Sandbox mode with 12 textured blocks + day/night cycle + particle effects
- Endless Run and Visitor roam modes
- BFS pathfinding guarantees solvable mazes with reachable keys
- World pre-generation cache saved to App Data for instant load
- Bilingual Chinese / English UI (switch in menu with ← / →)

## Controls

| Key | In-game | MC Mode |
| --- | --- | --- |
| Up / Down | Move forward / backward | Same |
| Left / Right | Turn | Same |
| OK (short) | Shoot / Confirm | Place block |
| OK (long) | — | Mine block |
| Back (short) | Pause | Cycle held block |
| Back (long) | Exit to home | Same |
